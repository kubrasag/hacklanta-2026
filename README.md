## Requirements

- [Node.js](https://nodejs.org) version 18 or newer
- npm (comes with Node.js)
- A modern browser such as Chrome, Firefox or Safari

You can check your Node.js version with this command.

```bash
node -v
```

## Installation

1. Clone the repository.

```bash
   git clone https://github.com/kubrasag/hacklanta-2026.git
```

2. Go into the project folder.

```bash
   cd hacklanta-2026
```

3. Install the dependencies.

```bash
   npm install
```

4. Start the development server.

```bash
   npm run dev
```

5. Open the address shown in the terminal in your browser. It is usually `http://localhost:8080`. If that port is busy, Vite picks the next free one, for example `8081` or `8082`.

The page reloads automatically when you save a file.
